# Portfólio de Infraestrutura de TI

Três laboratórios que, juntos, montam a TI de um escritório pequeno do zero:

1. **A rede** onde tudo se conecta
2. **O servidor** que controla usuários, arquivos e permissões
3. **O sistema de chamados** usado para dar suporte a esse ambiente

```
   [ 01 - Rede ]  →  [ 02 - Windows Server / AD ]  →  [ 03 - GLPI ]
   cabos, Wi-Fi,     usuários, grupos, pastas,        chamados, inventário,
   VLANs, DHCP       permissões, GPOs                 login pelo AD
```

## Projetos

| # | Projeto | Tecnologias | Status |
|---|---|---|---|
| 01 | [Rede de escritório pequeno](01-rede-packet-tracer/) | Cisco Packet Tracer, VLAN, DHCP, Wi-Fi, ACL | 🟡 Em andamento |
| 02 | [Laboratório Windows Server](02-windows-server-ad/) | VirtualBox, Windows Server, Active Directory, GPO, NTFS | ⚪ Próximo |
| 03 | [Sistema de chamados](03-glpi-chamados/) | Ubuntu Server, Apache, MariaDB, PHP, GLPI, LDAP | ⚪ Próximo |

## Por que esses projetos

São as tarefas do dia a dia de suporte e infraestrutura em empresas pequenas e médias. Também são os serviços que ofereço como técnico de TI autônomo.
